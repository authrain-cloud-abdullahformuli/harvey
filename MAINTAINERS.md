## Responsibilities

Maintainers oversee:
- Architecture, design, and roadmap execution
- Code reviews, pull requests, and releases
- Issue triage, bug fixes, and security patches
- Model prompt safety, headless CLI integration, and provider plugins

## Contributions

We welcome open-source contributions! To contribute:
1. Fork the repository
2. Create your feature branch (`git checkout -b feature/amazing-feature`)
3. Commit your changes (`git commit -m 'feat: add amazing feature'`)
4. Push to the branch (`git push origin feature/amazing-feature`)
5. Open a Pull Request
